# Goblin Maze Defense (YouTube Playable)

Single-file HTML5 tower-defense game with YouTube Playables SDK hooks.

## Host on GitHub Pages
1. Create a new repo and upload `index.html` to the root.
2. Settings > Pages > Source: Deploy from a branch > main / root > Save.
3. Open https://<username>.github.io/<repo>/ to play.

## Test with the Playables Test Suite
Open the Playables SDK Test Suite and enter your GitHub Pages URL as the Game URL.
